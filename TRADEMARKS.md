# Trademark policy

The Apache-2.0 licence covers the source code. It does not grant rights to the
name Dubbit, the logo or the mascot.

## What you may do

- Fork the code and change what you need, as long as the licence, the copyright
  notice and the NOTICE file stay with the code.
- Say in plain text that your work is based on Dubbit or compatible with it.
- Use the name to refer to the original project in articles, reviews, tutorials
  and comparisons, as long as it is clear you are not the project.

## What you may not do

- Use the name, the logo or the mascot in a way that suggests your fork, build,
  service or product is the official project or is endorsed by it.
- Publish a modified build under the Dubbit name. Forks must use a different
  name and a different logo.
- Register domains, accounts, packages or store listings that imitate the
  official ones.
- Use the name of the project in advertising that implies sponsorship.

## Parody and commentary

Clearly labelled parody and commentary that cannot be mistaken for the project
are allowed. Do not use the logo in a way that misleads people about the source
of the software.

## Official channels

The official repository, its releases and its discussions are the only
official channels. Release artefacts carry SHA-256 checksums; compare them
before running a binary. If a build claims to be Dubbit and does not come from
those channels, treat it as unofficial.

## Reporting misuse

Report misuse of the name or logo to the maintainer through the contact options
on the repository profile. Reports about malware or impersonation are handled
first. Requests to a platform for removal follow the licence and trademark
terms of that platform.
